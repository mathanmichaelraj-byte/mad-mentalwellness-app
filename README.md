# Android Mental Wellness & Location Support Application

## Project Overview
The Android Mental Wellness & Location Support Application is a native Android application developed using Java and Android Studio. The application focuses on promoting emotional well-being through mood tracking, emotional self-expression, and location-based support features. It provides a calm and user-friendly interface designed to reduce stress and encourage emotional awareness.

The application avoids complex AI-based systems and instead uses rule-based logic, local storage, and GPS services, making it simple, reliable, and suitable for academic and practical use.

## Features
- Motivational welcome and emotional onboarding
- Daily mood tracking using simple inputs
- Emotional hormone level calculation (Serotonin, Dopamine, Oxytocin)
- Temporary emotional release notes with auto-delete
- GPS-based therapist and calming area finder
- Push notifications and reminders
- Local data storage using SQLite
- Firebase-based SMS and Email communication
- SD card data storage support
- Smooth animations and graphical UI elements

## Technology Stack
- Programming Language: Java
- IDE: Android Studio
- User Interface: XML Layouts
- Database: SQLite
- Cloud Services: Firebase
- Location Services: Google Play Services (GPS, Geofencing)

## Emotional Hormone Calculation
The application uses a non-medical, rule-based calculation to estimate emotional hormone levels based on user mood inputs.

Hormones considered:
- Serotonin – Mood stability
- Dopamine – Motivation and energy
- Oxytocin – Emotional comfort

The calculated levels are categorized as Low, Normal, or High and are used only to provide supportive wellness suggestions.

## Installation and Setup
1. Install Java Development Kit (JDK)
2. Install Android Studio
3. Configure Android SDK
4. Open the project in Android Studio
5. Connect Firebase for SMS and Email services
6. Enable GPS and location permissions
7. Run the application on an emulator or Android device

## Permissions Used
- Location (GPS)
- Internet
- External Storage (SD Card)
- Notifications
