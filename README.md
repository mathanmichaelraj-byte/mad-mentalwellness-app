MENTAL WELLNESS APP

Emotionally Intelligent Support Through Behavioral Tracking & NLP


OVERVIEW

A Flutter-based mental wellness application designed to provide emotional support through passive behavioral tracking, NLP-driven insights, and interactive calming tools — while ensuring complete user privacy.


CORE FEATURES

- Enhanced Emotional Intelligence (NLP)
- Rule-Based + Hybrid Analysis
- Automatic Behavioral Tracking
- Mood Journal (NLP Integrated)
- Smart Emotional Support System
- Dynamic Affirmations
- Smart Notifications
- Calm Audio Therapy
- Interactive Breathing Exercises
- Progress Dashboard (Animated)
- Location Finder
- Privacy First Design


EMOTION INTELLIGENCE SYSTEM

- Context-aware sentiment analysis
- Processes journal + user input
- Combines behavioral + textual data
- Detects emotional states with high accuracy
- Dynamically updates user emotional profile


MOOD JOURNAL

- Stores entries locally using SQLite
- NLP-based sentiment & emotion detection
- Contributes to overall emotional analysis
- Real-time reflection in user state


USER EXPERIENCE ENHANCEMENTS

- Creative & personalized affirmations
- Emotion-based support system (appears only when needed)
- Smooth breathing animations with guided pacing
- Reliable meditation & ambient audio playback


PROGRESS TRACKING

- Emotional trend analysis
- Animated charts for better visualization
- Smooth UI transitions
- Elegant and engaging dashboard


HOW IT WORKS

Step 1: Passive Tracking
- Monitors user behavior automatically
- Tracks usage patterns, session time, and interaction speed

Step 2: Emotional Input
- "Share Feelings" dialog (auto + manual)
- Mood journal entries stored locally
- NLP analyzes user text input

Step 3: Hybrid Analysis
- Combines behavioral data + NLP insights
- Detects emotional state with confidence scoring

Step 4: Emotional Detection
- States: calm, restless, stressed, lowEnergy, neutral, distressed
- Updates dynamically in real-time

Step 5: Intelligent Response
- Triggers affirmations, support UI, notifications
- Support shown only when user is distressed

- On-device NLP Processing


PRIVACY

- No cloud sync
- No data sharing
- No background tracking
- Full user control
